# Kho đề Olympic Vật lý

Website tĩnh (static) liệt kê đề thi Olympic Vật lý và tuyển tập chuyên đề do page [Physics Translate](https://www.facebook.com/physicstranslatevn) đăng tải. Chỉ là mục lục + link về bài gốc — không lưu trữ lại file/ảnh.

- `index.html` — giao diện (tìm kiếm, lọc theo chuyên mục/năm)
- `data/posts.json` — dữ liệu catalog, được cập nhật hàng tuần
- `scripts/build.py` — script dựng bản đầu tiên của `posts.json`
